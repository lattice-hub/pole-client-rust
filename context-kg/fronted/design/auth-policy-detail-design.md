# 权限策略详情 — 设计交接文档

> 适用范围：Pole.IO 控制台 → 认证管理 → 权限策略 → **策略详情抽屉**。
> 对应原型文件：`auth-policy-detail.html`。
> 本文档描述当前原型的页面结构、查看态交互、资源授权信息组织与实现注意事项，供后续实现或继续优化参考。
> **重要边界：本设计只调整前端详情页的信息组织和交互表达，不调整后端权限策略模型、接口契约或资源授权语义。**

---

## 1. 设计目标

权限策略详情的核心任务是帮助用户快速回答三件事：

1. 这条策略是谁的、从哪里来、当前效果是什么。
2. 当前成员如何进入这条策略。
3. 这个成员能访问哪些资源类型、哪些资源范围，以及这些范围是新增继承还是显式授权。

最终形态是一个**轻量查看态详情抽屉**，不是编辑器。

关键结论：

1. 详情抽屉顶部只保留策略标题、状态标签和必要元信息。
2. 成员、资源、标签、接口通过页签分区，不在顶部堆叠摘要卡。
3. 资源类型属于「资源信息」页签内部的操作上下文，不放到概要区抢主信息。
4. 右侧「授权概览」辅助栏不需要；详情页保持单栏结构。
5. 查看态不展示「编辑 / 关闭」按钮，也不展示底部固定操作栏。
6. 复制、搜索、筛选、行选择、遮罩关闭和 Esc 关闭属于查看态可保留的轻量交互。

---

## 2. 页面整体结构

页面由三层组成：

```text
权限策略页面
├── 左侧 Console 导航
├── 中间权限策略列表
└── 右侧策略详情抽屉
    ├── 抽屉头部：标题 + 策略状态标签
    ├── 策略概要：名称、描述、ID、来源、时间、成员、接口状态
    └── 页签内容
        ├── 成员信息
        ├── 资源信息
        ├── 资源标签
        └── 可访问接口
```

抽屉宽度：

```css
width: min(980px, 94vw);
```

这样能容纳资源信息里的左侧资源类型导航和右侧授权表格，同时避免像双栏概览那样占据过宽空间。

---

## 3. 抽屉头部

当前头部只包含：

| 元素 | 说明 |
|---|---|
| `策略详情` | 抽屉标题 |
| `允许` | 策略效果状态 |
| `默认策略` | 策略来源 / 类型提示 |

不展示：

- 编辑。
- 取消编辑。
- 保存变更。
- 关闭按钮。
- 更多操作。

关闭能力保留在底层交互里：

- 点击遮罩关闭。
- 按 Esc 关闭。

这样可以避免右上角操作区挤占主信息，详情页也不会误导用户以为当前页面支持完整编辑流程。

---

## 4. 策略概要

概要区承担「先确认当前策略对象」的任务。

结构：

```text
策略概要
├── 图标 badge
├── 策略名称
├── 策略描述
├── 复制 ID
└── 元信息网格
    ├── 策略 ID
    ├── 来源
    ├── 创建时间
    ├── 更新时间
    ├── 策略标签
    ├── 成员
    └── 可访问接口
```

布局约束：

1. 策略 ID 是长字符串，必须跨两列展示。
2. 策略 ID 使用等宽字体，并允许长字符串断行。
3. 「复制 ID」按钮保持单行，不被压成两行。
4. 不展示「资源类型 N 类」这类汇总字段。

当前原型里的关键类：

| 类名 | 用途 |
|---|---|
| `.summary` | 策略概要容器 |
| `.summary-top` | 标题、描述和复制按钮区域 |
| `.summary-copy` | 固定宽度的复制 ID 按钮 |
| `.meta-grid` | 元信息网格 |
| `.meta.wide` | 策略 ID 跨列 |
| `.v.mono.break` | 长 ID 等宽换行 |

## 5. 页签结构

页签固定为四个：

```text
成员信息 / 资源信息 / 资源标签 / 可访问接口
```

页签职责：

| 页签 | 作用 |
|---|---|
| 成员信息 | 展示策略绑定到谁，以及策略如何对成员生效 |
| 资源信息 | 展示成员可访问的资源类型和授权范围 |
| 资源标签 | 展示可选的标签约束；当前为空状态 |
| 可访问接口 | 展示 Console API 访问范围 |

默认打开「成员信息」。

当切换到「资源信息」时，需要渲染资源类型列表和授权表格。

---

## 6. 成员信息

成员信息页签分为两块：

```text
成员信息
├── 成员卡
└── 生效路径

策略摘要
└── 定义列表
```

### 6.1 成员卡

成员卡展示：

| 信息 | 当前值 |
|---|---|
| 成员名称 | `admin` |
| 成员类型 | 用户 |
| 绑定方式 | 默认策略自动绑定 |
| 绑定状态 | 已绑定 |
| 成员标记 | 默认成员 |
| 成员 ID | `user/admin` |

保留轻量操作：

- 复制成员。

不展示：

- 添加成员。
- 移除成员。
- 修改成员。

### 6.2 生效路径

生效路径用 1-2-3 步解释策略如何作用到成员：

```text
1. 匹配成员
2. 读取策略效果
3. 进入资源范围
```

这个结构用于替代原截图里分散的字段堆叠，让用户理解「成员」和「资源范围」之间的关系。

### 6.3 策略摘要

策略摘要只放稳定的定义项：

| 字段 | 说明 |
|---|---|
| 策略效果 | 允许 |
| 默认策略 | 是 |
| 来源 | 系统默认策略 |
| 描述 | `default main user auth policy rule` |

不在这里重复资源类型统计。

---

## 7. 资源信息

资源信息是当前详情抽屉的主要交互区。

结构：

```text
资源信息
├── 左侧资源类型导航
│   ├── 搜索资源类型
│   ├── 全部资源 / 仅看新增继承
│   └── 资源类型列表
└── 右侧授权范围
    ├── 当前资源类型标题与说明
    ├── 复制清单
    ├── 授权范围摘要
    ├── 授权资源表格
    └── 分页
```

### 7.1 左侧资源类型导航

资源类型列表展示：

| 内容 | 说明 |
|---|---|
| 资源类型名称 | 例如命名空间、服务、配置组、路由规则 |
| 状态点 | 蓝色表示新增继承，黄色表示显式资源 |
| 范围说明 | `覆盖新增资源` 或 `仅显式资源` |
| 数量 | 当前资源类型下的授权行数 |

当前资源类型包括：

```text
命名空间、服务、配置组、路由规则、泳道规则、熔断规则、
主动探测规则、无损规则、限流规则、调用鉴权规则、
流量镜像规则、流量 Mock 规则、用户
```

搜索只筛选资源类型名称，不改变授权数据。

### 7.2 资源筛选

筛选按钮：

| 按钮 | 行为 |
|---|---|
| 全部资源 | 展示当前资源类型下的所有授权行 |
| 仅看新增继承 | 只展示授权方式为新增继承的行 |

切换筛选后：

1. 清空当前行选择。
2. 更新按钮高亮。
3. 更新表格内容。
4. 更新行数与当前选择数量。
5. 弹出 toast 反馈。

### 7.3 右侧授权范围摘要

摘要有三格：

| 字段 | 说明 |
|---|---|
| 授权范围 | 当前表格第一条授权范围；无数据时显示 `—` |
| 授权方式 | `新增继承` 或 `显式资源` |
| 当前选择 | 当前勾选行数 |

摘要只解释当前资源类型，不扩展成全局授权概览侧栏。

### 7.4 授权资源表格

表格列：

| 列 | 说明 |
|---|---|
| 勾选 | 支持单选和全选 |
| 资源 ID | 等宽显示 |
| 资源名称 | 资源可读名称 |
| 授权方式 | `包括新增` 或 `显式资源` |
| 操作 | 复制资源 ID |

空状态：

```text
当前资源类型没有“新增继承”范围，可切回全部资源查看显式授权。
```

这个空状态只在「仅看新增继承」且当前资源类型没有继承行时出现。

### 7.5 分页

分页在当前原型中是展示态：

```text
共 N 条数据 / 1 / 10 条/页 / 跳至 1 / 1 页
```

后续真实实现可接入服务端分页或前端分页，但不应把分页变成设计说明控件。

---

## 8. 资源标签

当前默认策略没有资源标签。

页面展示空状态：

```text
暂无资源标签。默认策略通过资源类型和资源范围生效。
```

不展示新增标签入口。

---

## 9. 可访问接口

接口页签展示默认策略可访问的 Console API 分组。

当前表格：

| 接口分组 | 访问范围 | 状态 |
|---|---|---|
| 权限策略 API | `/auth/v1/policies/**` | 允许 |
| 资源查询 API | `/auth/v1/resources/**` | 允许 |

接口页签用于解释 Console 能力范围，不承担后端接口调试或权限编辑功能。

---

## 10. 查看态交互

当前保留的交互：

| 交互 | 函数 | 说明 |
|---|---|---|
| 打开抽屉 | `openDrawer()` | 列表点击后展示详情 |
| 关闭抽屉 | `closeDrawer()` | 遮罩点击或 Esc |
| 切换页签 | `switchTab(id)` | 成员、资源、标签、接口 |
| 搜索资源类型 | `renderResourceList()` | 按资源类型名称过滤 |
| 切换资源类型 | 内联点击事件 | 更新左侧选中与右侧表格 |
| 切换资源筛选 | `setResourceFilter(inheritedOnly)` | 全部资源 / 仅看新增继承 |
| 勾选资源行 | `toggleRow(i)` | 更新当前选择 |
| 全选资源行 | `toggleAllRows(count)` | 当前表格范围内全选 |
| 复制成员 | `copyMember()` | 复制 `admin` |
| 复制策略 ID | `copyPolicyId()` | 复制策略 ID |
| 复制资源 ID | `copyResourceId(id)` | 复制单行资源 |
| 复制资源清单 | `copyResourceRows()` | 复制当前资源类型下的授权行 |
| Toast 反馈 | `toast(text)` | 复制和筛选动作反馈 |

不保留的交互：

- 编辑。
- 保存。
- 添加成员。
- 移除成员。
- 添加资源。
- 添加标签。
- 抽屉内关闭按钮。
- 底部固定操作栏。
- 右侧授权概览联动。

---

## 11. 视觉与密度规则

视觉体系沿用 Pole.IO 控制台 / Ant Design 风格：

- 左侧浅灰导航。
- 主体白色面板。
- 蓝色作为主操作与选中状态。
- 成功、警告状态用轻量 tinted pill。
- 表格保持紧凑密度。
- 抽屉单栏布局，内容自然滚动。

密度约束：

1. 详情页不要为了“看起来完整”增加概览侧栏。
2. 顶部概要只保留识别策略所需的信息。
3. 资源类型上下文只在资源信息页签内展示。
4. 查看态不制造提交区，不预留底部操作栏高度。
5. 长字段必须换行或跨列，不允许覆盖相邻字段。

## 13. 反回归清单

后续修改这个页面时，需要避免以下回退：

- 不要恢复顶部「资源类型 N 类」汇总。
- 不要恢复右侧「授权概览 / 当前资源类型 / 最近变更」侧栏。
- 不要恢复抽屉头部「编辑 / 关闭」按钮组。
- 不要恢复底部固定操作栏。
- 不要在成员页签加入添加、移除或编辑动作。
- 不要在资源信息页签外再做资源类型总览。
- 不要把查看态页面改成编辑器，除非产品明确增加独立编辑流程。
- 不要把截图整张导入为图片；交互必须由 HTML 结构和真实控件表达。
- 不要用设计说明文案替代产品文案。
- 不要让长策略 ID 挤压相邻字段。
- 不要在原型里残留 `drawer-aside`、`edit-only`、`view-only`、`drawer-foot`、`setEdit`、`saveEdit`、`addResource`。

---

## 14. 验证建议

每次修改后至少做以下检查：

1. 抽取内联脚本并执行语法检查。
2. 搜索确认冗余结构没有回归：

```text
授权概览
drawer-aside
资源类型 13 类
drawer-foot
edit-only
view-only
setEdit
saveEdit
addResource
>关闭<
>编辑<
```

3. 检查关键锚点仍存在：

```text
#drawer
#tab-members
#tab-resources
#resourceList
#resourceTable
#filterAllBtn
#filterInheritedBtn
copyPolicyId
copyMember
copyResourceRows
```

4. 如果渲染通道可用，打开 `auth-policy-detail.html` 检查：
   - 抽屉默认可见。
   - 概要区长 ID 不挤压。
   - 成员信息页签可读。
   - 资源信息页签搜索、筛选、选择、复制反馈可用。
   - 页面没有右侧概览栏和底部固定操作栏。
